## Authz And Audit Rules In Force

- Default deny.
- Assignment controls visibility.
- Club membership alone does not grant medical, safeguarding, finance, coach-private, or family-private access.
- Assistant/staff access is narrower than owner/head-coach access unless an explicit grant widens it.
- API actors come from bearer auth, not caller-supplied user IDs.
- Sensitive reads/writes/removals are audited, including health, safeguarding, trust reports, sessions, money transitions, payout method removal, direct payment instructions, and club archive.
- Human-facing delete semantics should render as archive, remove, dismiss, revoke, cancel, or void. Raw hard-delete wording is not the product truth for trust/money/history surfaces.
